# 서드파티 보안 검색을 통해 발견된 취약점은 [!DNL HackerOne]&#x200B;(으)로 이동해야 합니다.

이 문서에서는 서드파티 보안 검색으로 발견된 취약점을 해결하는 솔루션을 제공합니다.

## 영향을 받는 제품 및 버전

* Adobe Commerce (모든 버전)

## 문제

상인은 독립적인 보안 기관을 통해 PEN 테스트를 수행하였고, 취약점에 대한 플래그가 지정되었다.

## 솔루션

타사 보안 검색에서 발견된 취약성은 [!DNL HackerOne] 웹 사이트로 전송해야 합니다. Adobe Commerce은 [!DNL HackerOne]에 직접 연락처가 없으므로 [!DNL HackerOne]에 직접 연결해야 합니다. Adobe은 MST(Magento Security Scan Tool) 보고서만 처리합니다.
